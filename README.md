# 트라다다 GO

전통시장을 여행처럼 걷고, 마감할인 음식을 예약하고, 방문할 때마다 지도를 색칠하는 데모 앱입니다.

너무 굿 투 고(Too Good To Go)의 **남은 음식 할인 픽업**과 포켓몬 GO의 **가서 인증하고 모으는 재미**를 한곳에 모았습니다.

- 소비자는 할인된 음식을 사고, 시장을 탐험하며 스탬프·칭호를 모읍니다.
- 상인은 버려질 뻔한 재고를 매출로 바꿉니다.
- 공공은 음식물 쓰레기 감축, 상권 활성화, 지역화폐 유통을 한 앱에서 보여 줄 수 있습니다.

> 시장도 여행처럼! 혜택은 보물처럼!

지금은 **실제 서버 없이 휴대폰(또는 에뮬레이터) 안에서만 동작하는 시연용 빌드**입니다. 로그인하면 광주 전통시장 지도가 열리고, 두 곳의 시장을 들어가 볼 수 있습니다.

---

## 이 앱으로 무엇을 하나요?

한 줄로 말하면 **시장에 가서 → 가게 앞에서 QR을 찍고 → 리뷰를 쓰면 → 지도가 칠해지고 스탬프가 쌓입니다.**

| 하고 싶은 일 | 어디서 |
| --- | --- |
| 시장·가게 찾기 | 하단 **홈** 지도 |
| 골목을 따라 걸어보기 | 시장 안에서 **골목 시연 걷기** |
| 방문 인증 | 노란 가운데 버튼(QR) 또는 가게 상세의 QR |
| 마감할인 음식 예약 | 가게 상세 → 상품 예약 |
| 예약·방문 기록 보기 | 하단 **이용내역** |
| 다른 사람 리뷰·추천 루트 | 하단 **커뮤니티** |
| 스탬프·칭호·색칠한 지도 | 하단 **마이페이지** |

에뮬레이터에는 GPS가 거의 없으므로, 실제 걷는 대신 **골목 시연 걷기**로 캐릭터가 시장 안을 이동합니다.

---

## 화면 안내

하단에는 네 개 탭과, 가운데에 노란 **스탬프(QR)** 버튼이 있습니다.

### 홈

광주 시내 네이버 지도가 열리고, 전통시장 핀이 찍혀 있습니다.

- **양동시장** — 실제 양동시장 권역을 본뜬 조감도. 가게 핀과 마감할인 상품이 있습니다.
- **시장 데모** — 시장 내부 평면도를 위에서 내려다보는 시연 지도입니다. 점포 칸이 많고, 리뷰를 쓰면 칸이 색칠됩니다.
- **대인시장** — 지도에 위치만 있고, 아직 안은 열리지 않습니다.

시장 핀을 누르면 그 시장 안으로 들어갑니다. 왼쪽 위 뒤로 가기로 광주 지도로 돌아옵니다.

### 시장 데모 (내부 지도)

홈에서 **시장 데모**를 누르면 나오는 화면입니다.

1. **위쪽** — 시장 이름, 카테고리 선택, 1층/2층, 가게 정보 보기
2. **가운데** — 골목과 점포 칸. 캐릭터가 서 있고, 가까운 가게가 노란 말로 안내됩니다.
3. **아래쪽**
   - **골목 시연 걷기** — 캐릭터가 복도를 따라 자동으로 걷습니다. 걷는 중에는 일시정지 / 이어서 걷기 / 시연 경로 정지를 쓸 수 있습니다.
   - **색칠 게이지** — 리뷰로 칠한 점포 비율입니다. 왼쪽이 `색칠 12%` 같은 퍼센트, 가운데가 노란 막대, 오른쪽이 `3/200곳`처럼 칠한 칸 / 전체 칸입니다.

가게 칸을 탭하면 마감할인·QR 인증 화면이 열립니다. 지도를 두 손가락으로 확대·축소할 수 있습니다.

### 양동시장

조감도 위에 가게 핀이 있습니다. 시연 걷기로 핀에 가까워지면 핀이 켜지고, QR을 찍을 수 있습니다. 가게당 **하루 1회** 방문 스탬프가 쌓입니다.

### 이용내역

QR 방문과 마감할인 예약 목록입니다. 방문한 가게에는 여기서 리뷰를 쓸 수 있습니다.

### 커뮤니티

- **리뷰** — 포토 리뷰와 주간 추천 랭킹(2등 · 1등 · 3등 순으로 보여 줍니다).
- **추천 루트** — 시장을 여행지처럼 걷는 안내 코스입니다.

리뷰 추천은 **하루 2회**까지입니다. 추천을 10번 모으면 스탬프가 하나 더 생깁니다.

### 마이페이지

- 스탬프를 모은 **우표 보드**(5×6)
- 안 가본 가게를 많이 방문하면 열리는 **칭호** (탐방가 10곳 / 전문가 30곳 / 마스터 50곳)와 상품권
- 스탬프 30개마다 지역사랑상품권 1만 원
- **내가 완성한 지도** — 리뷰로 색칠된 평면도를 다시 봅니다.

리뷰를 쓰면 해당 가게 칸이 지도에서 색이 입혀집니다. 게이지의 퍼센트는 이 색칠된 칸의 비율입니다.

## 처음 시연할 때 (추천 순서)

1. 로그인합니다. 아이디 `admin`, 비밀번호 `tradada123`.
2. 홈에서 **시장 데모** 핀을 누릅니다.
3. **골목 시연 걷기**를 누르고, 캐릭터가 가게 옆에 서면 노란 안내를 탭합니다.
4. **QR 인증하기** → 에뮬레이터면 **에뮬레이터 시연 인증**을 누릅니다.
5. 이용내역에서 그 방문을 열어 **포토 리뷰**를 작성합니다. (시연용 사진 중 하나를 고르면 됩니다.)
6. 시장 데모로 돌아오면 해당 칸이 칠해지고, 하단 게이지의 %가 올라갑니다.
7. 마이페이지에서 우표 보드와 **내가 완성한 지도**를 확인합니다.

양동시장도 같습니다. 홈 → 양동시장 → 골목 시연 걷기 → 켜진 핀에서 QR → 리뷰.

가운데 노란 버튼을 눌러도, 지금 서 있는 가게의 QR 화면으로 들어갑니다. 시장 안에 들어가기 전에 누르면 “시장 핀을 눌러 조감도로 들어가세요”라고 안내합니다.

## 이 데모에서 알아 두면 좋은 규칙

- **방문 스탬프**는 가게당 하루 1회입니다. 같은 가게를 다시 QR해도 이용내역에는 남지만, 오늘 스탬프는 한 번입니다.
- **지도 색칠**은 내가 쓴 리뷰가 있는 가게만 반영됩니다. QR만 찍고 리뷰를 안 쓰면 게이지는 그대로입니다.
- **칭호**는 “한 번도 안 가본 가게”를 몇 곳 방문했는지만 셉니다. 리뷰 보너스 스탬프는 칭호에 넣지 않습니다.
- 데이터는 앱을 끄면 초기화될 수 있습니다. 서버에 저장하지 않습니다.

## 실행 방법

네이버 지도 SDK를 쓰므로 **Android 에뮬레이터 또는 Android 실기기**에서 실행하세요. Windows 창이나 Chrome에서는 지도가 뜨지 않습니다.

필요한 것: [Flutter](https://docs.flutter.dev/get-started/install), Android Studio, Android 에뮬레이터.

```powershell
cd C:\Users\hanji\dev\tradada3\TradadaGo

# 에뮬레이터가 꺼져 있으면 먼저 켭니다
flutter emulators --launch Medium_Phone_API_35

# 기기가 보이는지 확인합니다. 비어 있으면 에뮬레이터 창이 아직 없는 상태입니다
adb devices

flutter run -d emulator-5554
```

패키지 이름: `com.foodridge.foodridge`

### 임시 시연 계정

| 아이디 | 비밀번호 |
| --- | --- |
| `admin` | `tradada123` |

### 실행이 안 될 때

`adb devices`가 비어 있으면 에뮬레이터가 꺼진 것입니다. Android Studio Device Manager에서 에뮬레이터를 켠 뒤, 창이 뜬 다음에 다시 `adb devices`를 실행하세요.

앱은 에뮬레이터에 떠 있는데 Android Studio에 `Lost connection to device` 또는 `Error connecting to the service protocol`가 뜨면, 앱이 죽은 것이 아니라 **PC와 에뮬레이터를 잇는 디버그 연결이 끊긴 것**입니다. 핫 리로드만 안 될 수 있습니다. 에뮬레이터를 한 번 종료했다가 다시 켜고 `adb kill-server` 후 `flutter run`을 다시 해 보세요. 그래도 같으면 `flutter run --no-dds`로 실행할 수 있습니다.

## 지도가 두 종류인 이유

| | 광주 시내 지도 | 시장 안 지도 |
| --- | --- | --- |
| 언제 | 홈에서 시장을 고를 때 | 시장 핀을 누른 뒤 |
| 엔진 | 네이버 클라우드 지도 | 앱이 그리는 평면도·조감도 |
| 내용 | 시장 위치 핀 | 가게 칸, 캐릭터, QR, 색칠 |

가게 좌표는 시연용으로 그림 골목에 맞춰 두었습니다. 나중에 실제 점포 위치와 다시 맞추면 됩니다.

네이버맵 Client ID는 `lib/config/env.dart`에 있습니다. **Client Secret은 앱에 넣지 않습니다.**

## 코드는 어디에 있나요?

앱을 고치고 싶을 때 보는 폴더입니다. 사용만 할 때는 건너뛰어도 됩니다.

```
lib/
  screens/     로그인, 홈, 내부 지도, 가게, QR, 마이페이지
  widgets/     조감도, 색칠 게이지, 하단 탭
  data/        양동시장 가게, 시장 데모 평면도
  state/       로그인, 스탬프, 예약, 위치·시연 걷기
  map/         평면도 그리기, 카메라(확대·이동)
assets/        로고, 핀, 아바타, 점포 데이터
```

내부 지도 화면은 `lib/screens/sangju_indoor_map_screen.dart`, 색칠 게이지는 `lib/widgets/market_map_controls.dart`의 `PaintProgressBanner`입니다.
