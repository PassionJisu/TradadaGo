# 트라다다 GO!

전통시장 활성화 정책 지원 앱 데모입니다.  
**Too Good To Go**(마감할인 예약·픽업)와 **포켓몬 GO**(위치 기반 스탬프)를 결합해, 소비자는 할인·수집의 재미를, 상인은 폐기 손실의 수익 전환을, 공공은 음식물 쓰레기 감축·상권 활성화·지역화폐 유통을 한 앱에서 노립니다.

> 시장도 여행처럼! 혜택은 보물처럼!

현재 빌드는 솔버톤/데모용으로 **지도·아바타·가게 핀·QR 스탬프·마감할인 예약**에 집중합니다. 스탬프 보드, 리뷰 랭킹, 회원가입은 다음 단계입니다.

## 1차 데모에서 되는 것

1. **지역 네이버맵** — 광주 전통시장 핀만 표시 (양동·대인·말바우)
2. **시장 입장** — 양동시장 핀을 누르면 포켓몬 GO 스타일 조감도로 전환, 그 시장 가게만 표시
3. **아바타** — 조감도에 들어갔을 때만 등장. 에뮬레이터는 `골목 시연 걷기`로 이동
4. **가게 핀** — 가까이 가면 활성화, 탭하면 원가/할인가 확인 후 픽업 예약
5. **QR 스탬프** — GPS 근접 + QR(또는 시연 인증). 가게당 세션 1회

## 실행 방법

Android 에뮬레이터에서 실행합니다. 네이버맵 모바일 SDK라 Windows/Chrome에서는 지도가 뜨지 않습니다.

```bash
flutter emulators --launch Medium_Phone_API_35
flutter run
```

패키지 / 번들 ID: `com.foodridge.foodridge`

### 시연 순서

1. 로그인
2. 광주 지도에서 **양동시장** 핀 선택
3. **골목 시연 걷기** → 아바타가 가게 핀을 지나며 활성화
4. 핀 탭 → 마감할인 상품 예약 / QR 스탬프

대인시장·말바우시장 핀은 지역 지도용이며, 1차 점포 데이터는 양동시장만 있습니다.

## 지도 설계

| 화면 | 엔진 | 내용 |
| --- | --- | --- |
| 1차 (지역) | 네이버 클라우드 Dynamic Map | 시장 위치 핀만 |
| 2차 (시장) | 조감도 이미지 + GPS/시연 경로 | 가게 핀, 아바타, QR |

조감도 위 가게 좌표는 데모용으로 일러스트 골목에 맞춰 두었습니다. 이후 실제 점포 좌표와 조감도를 다시 정렬하면 됩니다.

네이버맵 Client ID는 `lib/config/env.dart`에 있습니다. **Client Secret은 앱에 넣지 않습니다.**

## 프로젝트 구조 (핵심)

```
lib/
  screens/          로그인, 홈(지도), 가게 상세, QR
  widgets/          조감도 플레이 뷰, 하단 탭
  data/             양동시장 mock 가게·상품
  state/            로그인, 예약, 스탬프, 위치/시연 경로
assets/images/      로고, 핀, 아바타, 조감도
```
